# CatBox — IPTV-приставка

Простая IPTV-приставка с Web-UI на Electron.

## Возможности

- Выбор экрана: если есть второй монитор — окно открывается на нём, иначе на основном
- Стартовый экран с пейзажем и кнопкой «Смотреть ТВ»
- Автозапуск первого канала из `potocs.json`
- Переключение каналов:
  - ↑ / ↓ — предыдущий / следующий (слева выезжает список каналов на 2 сек)
  - Цифры 0–9 — прямой ввод номера (сверху справа появляется оверлей, 3 сек ожидания, можно вводить несколько цифр)
- Поддержка обычных HLS/m3u8/ts-потоков и ссылок через **yt-dlp** (`"source": "ytdlp"`)
- Курсор скрыт, появляется только при движении мыши
- Критические ошибки/краши опционально отправляются в ntfy (топик задаётся в `.env`, в репозиторий не попадает)

## Требования

- Node.js 18+
- **yt-dlp** (или youtube-dl) в PATH — обязательно для каналов с `"source": "ytdlp"`
  ```bash
  # Windows (winget / scoop / chocolatey)
  winget install yt-dlp

  # Linux
  sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
  sudo chmod a+rx /usr/local/bin/yt-dlp
  ```

## Установка и запуск

```bash
cd catbox
npm install
npm start
```

Для отладки:
```bash
npm run dev
```


## Настройка (.env)

Скопируй пример и укажи свой ntfy-топик (файл `.env` в git **не** коммитится):

```bash
cp .env.example .env
```

В `.env`:

```env
NTFY_TOPIC=your-private-topic-name
```

Либо полный URL:

```env
NTFY_URL=https://ntfy.sh/your-private-topic-name
```

Если переменная не задана — уведомления просто не отправляются.

## potocs.json

Файл должен лежать **в той же папке**, что и `main.js`.

```json
{
  "1": {
    "name": "Название канала",
    "description": "Опционально",
    "link": "https://example.com/stream.m3u8"
  },
  "4": {
    "name": "НТВ",
    "link": "https://rutube.ru/video/....",
    "source": "ytdlp"
  }
}
```

- Ключ — номер канала (целое число)
- `link` — прямая ссылка на поток (m3u8, m3u, ts и т.д.) или страница Rutube/YouTube/VK
- `source: "ytdlp"` — значит `link` нужно сначала прогнать через yt-dlp

Каналы сортируются по номеру. При старте плеера включается канал с наименьшим номером.

## Управление

| Клавиша       | Действие                          |
|---------------|-----------------------------------|
| ↑ / ↓         | Предыдущий / следующий канал      |
| 0–9           | Ввод номера канала                |
| Esc           | Выход из приложения               |
| Enter / Пробел| На стартовом экране — «Смотреть ТВ» |

## Замечания

- Воспроизведение идёт через HTML5 video + hls.js (Chromium отлично играет HLS).
- Полноценный встроенный libVLC в Electron требует native-модулей и сильно усложняет сборку/кроссплатформу, поэтому выбран стабильный веб-стек + yt-dlp.
- Обычные ошибки «поток недоступен» / «плохая ссылка» **не** отправляются в ntfy — только реальные краши и неожиданные исключения.
